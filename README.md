# Jonathan Muwanguzi - Enterprise AI & Cloud Portfolio

This repository contains the source code for my professional engineering portfolio, built to demonstrate scalable, resilient, and privacy-first AI architectures. 

The site is statically generated using [Quarto](https://quarto.org/) and deployed via GitHub Pages. It acts as a living document of my active deployments, research, and system designs across Edge, Cloud, and Data environments.

---

## 🏗️ Architectural Pillars

The portfolio is structured around three core engineering competencies, each demonstrating full-stack implementation and strict operational resilience:

### 1. Edge AI & Local Inference
**Focus:** Privacy-first systems, low-latency orchestration, and hardware-constrained inference.
* **Urban Pulse Engine:** District-level traffic orchestration using Proximal Policy Optimization (PPO) and deterministic spatial logic (DuckDB).
* **Civic Pulse Monitor:** Smart City operations utilizing federated geospatial graphs and local Llama 3 inference.
* **Eco Sentry (Edge):** An air-gapped cognitive firewall using TinyLlama and ChromaDB to explain unknown network anomalies.
* **Green-AI Pipeline:** Carbon-aware local agentic routing that dynamically switches between graph and vector memory based on real-time energy tracking.

### 2. Cloud-Native & Hybrid Systems
**Focus:** Scalable serverless pipelines, multi-agent orchestration, and API-driven hybrid logic.
* **Eco Sentry (Cloud Hybrid):** A "Satellite Command" unit bridging Google Gemini's infinite context with deterministic Neo4j graph logic via an asynchronous "Pulse" architecture.
* **Carbon-Aware Scheduler:** LangGraph multi-agent orchestration on AWS Lambda, executing heavy AI training workloads based on grid carbon intensity.
* **Serverless AI Pipeline:** Sub-100ms quality inspection pipeline utilizing AWS IoT Core, Greengrass, and PyTorch.

### 3. Data Engineering & Cognitive BI
**Focus:** Federated graph intelligence, RAG architectures, and probabilistic forecasting.
* **Lex-Ghost Architect:** An enterprise resilience platform utilizing GANs for threat simulation and PPO for recovery orchestration, controlled via an Agentic RAG War Room.
* **Churn Investigator:** Hybrid RAG orchestrating across SQLite and Neo4j to map systemic customer friction and predict churn.
* **EuroAgri Pipeline:** Semantic knowledge graphs for precision agriculture, featuring custom heuristic imputation for NPK soil data.
* **Net-Load Forecasting (Master's Dissertation):** Calibrated uncertainty and residual-based anomaly detection using MC-Dropout LSTMs and DeepSVDD on the Irish Power System.

## 🚀 Running the Project Locally

To preview the site locally as you make updates to the `.qmd` files:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Najo1on1/portfolio.git](https://github.com/Najo1on1/portfolio.git)
   cd portfolio
   ```

2. Ensure you have [Quarto installed](https://quarto.org/docs/get-started/).

3. Preview the site:
   ```bash
   quarto preview
   ```

4. To build the final static HTML files for deployment (outputs to the `/docs` directory):
   ```bash
   quarto render
   ```
